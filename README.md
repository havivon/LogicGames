# 🧩 חידות היגיון אינטראקטיביות

אתר סטטי (HTML/CSS/JS בלבד, בלי תלויות) עם שלוש חידות היגיון קלאסיות בעברית:

| חידה | מטרה | פתרון אופטימלי |
|---|---|---|
| 🐺 **חציית הנהר** | להעביר זאב, כבשה וחסה לגדה השנייה בלי שמישהו ייאכל | 7 חציות |
| 🐸 **קפיצת הצפרדעים** | 3 צפרדעים מול 3 צפרדעים מחליפות מקומות על 7 אבנים | 15 קפיצות |
| 🌉 **הגשר והנר** | 4 אנשים (1/2/5/10 דק') חוצים גשר בזוגות לפני שהנר כבה | 17 דקות בדיוק |

## הפעלה

פשוט פותחים את `index.html` בדפדפן — אין צורך בשרת או בהתקנה.

```bash
open index.html        # macOS
xdg-open index.html    # Linux
```

## מבנה

- `index.html` — כל המסכים (בית + שלוש החידות)
- `style.css` — עיצוב, RTL, אנימציות
- `app.js` — לוגיקת שלוש החידות (זיהוי ניצחון/הפסד, מונה מהלכים, ביטול מהלך)

# 🧩 חידות היגיון אינטראקטיביות

אתר סטטי (HTML/CSS/JS בלבד, בלי תלויות) עם שש חידות היגיון קלאסיות בעברית (RTL).

| חידה | מטרה | מיטבי |
|---|---|---|
| 🐺 **חציית הנהר** | להעביר זאב, כבשה וחסה לגדה השנייה בלי שמישהו ייאכל | 7 חציות |
| 🐸 **קפיצת הצפרדעים** | 3 צפרדעים מול 3 מחליפות מקומות על 7 אבנים | 15 קפיצות |
| 🌉 **הגשר והנר** | 4 אנשים (1/2/5/10 דק') חוצים גשר בזוגות לפני שהנר כבה | 17 דקות |
| 🗼 **מגדלי האנוי** | להעביר מגדל של 3 טבעות בלי טבעת גדולה על קטנה | 7 מהלכים |
| 🫙 **כדי המים** | בעזרת כד 3 ל' וכד 5 ל' למדוד בדיוק 4 ליטר | 6 מהלכים |
| 🛶 **מיסיונרים וקניבלים** | להעביר 3+3 בלי שהקניבלים יהיו רוב באף גדה | 11 חציות |

## תכונות

- 🎨 עיצוב "זכוכית" (glassmorphism) עם רקע חי, גרדיאנטים ואנימציות
- 🎉 קונפטי בכל ניצחון + חלון סיום מעוצב
- 🔊 צלילים (WebAudio, בלי קבצים) עם כפתור השתקה
- 💾 מעקב התקדמות שנשמר בדפדפן (`localStorage`) עם תגי "נפתר" ופס התקדמות
- ↩ ביטול מהלך במגדלים ובצפרדעים
- 📱 רספונסיבי, ומכבד `prefers-reduced-motion`

## הפעלה

פותחים את `index.html` בדפדפן — אין צורך בשרת או בהתקנה.

```bash
open index.html        # macOS
xdg-open index.html    # Linux
```

## מבנה

- `index.html` — כל המסכים (בית + שש החידות)
- `style.css` — עיצוב, RTL, אנימציות
- `app.js` — תשתית (ניווט, צלילים, קונפטי, התקדמות) ולוגיקת שש החידות
